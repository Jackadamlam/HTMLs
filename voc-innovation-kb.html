开场 · 四条心智对齐

先对齐心智，再讲方法。心智不对齐，方法论落地不了。

①

坚持

持续坚持方法论才能提升效果。VOC 是复利型能力：第一次做出来的是表格，第十次做出来的是判断力。产出直接接进立项评审，结课签 90 天承诺卡。

②

共识

思想对齐统一战线，动作同频。跨部门冲突多数不是利益冲突，是定义冲突。名词以术语表为准，结论必须写出公式、输入来源与置信度。

③

空杯

信息差红利时代过去。所有人都能拿到同一份评论、同一个大模型，差距只剩谁问得更准、谁执行得更细。开课写下最有把握的判断，Day2 用它做被证伪对象。

④

语言

统一话术就是统一思想。标签与需求句式不统一就无法聚类、统计、比较；不能比较就只能比职级。标签一律中性化，购买目的须通过「移除产品测试」。

我们不是来学一个新工具，是把一套判断标准变成肌肉记忆。如果结束时你觉得「都懂」，这门课就白上了——我们要解决的是：为什么懂了这么多年，产品方向还是靠吵。

创新与创造力 P02

创新 = 创造力（想法产生）+ 实施
创造力 = 有用 且 新颖 // 有用→有需求→找到用户需求（VOC 九步）；新颖→足够差异化→打破思维惯性（创意罗盘）

教材定义：创新是设计出满足用户需求的解决方案的过程，而这种需求之前并未得到满足。没有实施，创造力只是点子。

Innovation does not start out with an event in the environment, whether internal or external. It starts out with the job to be done.

创新的源泉来自于消费者的待办任务。

— Peter F. Drucker《创新与企业家精神》1985 · 课堂要求全场朗读中英原文

✗ 三个非法起点（环境事件）

  • 竞品出了新功能
  • 老板说要做 AI
  • 技术成熟了（供给推动）

✓ 唯一合法起点

  • 用户有一个没被完成的任务

误区纠正：有新技术≠创新（技术是手段）；功能越多≠越创新（堆料稀释差异化）；创新不必颠覆式（渐进式确定性最高）。

把创新变成数学题 · F1–F7

创新看起来是玄学，是因为大家只算到「我觉得」。把每个变量拆成可测量项，争论就变成计算——从「我觉得」到「我算过」。但打分不客观，公式就是装饰：每个分数都要能回溯到原声证据，这正是 step1→step4 存在的原因。

F1 爆品增长 = 机会人群 + 重要场景 + 未满足需求 + 产品创新 + 方案验证 + 有效营销
F2 机会分（理论参照）= 重要度 + MAX(重要度 − 满意度, 0) // 两项 1–10；≥15 高机会 / 12–14.99 可优化 / 10–11.99 同质化 / <10 过度服务
F3 需求强度 = 频次 × 强度 × 广度 // 强度只看行为（换品牌/加预算/等货），不听嘴
F4 创新得分 =（需求强度 × 目标人群规模 × 差异化可感知度）÷（实现成本 × 交付风险）// 用户 3 秒看不懂的差异等于没有差异
F5 付费意愿验证：预期提升 =（新概念偏好度 − 当前方案偏好度）÷ 当前方案偏好度 // 样本 ≥50，须配概念理解度筛选题
F6 机会人群判据（公司实操）= 人群规模合适 + 竞品满足度低 + 自身优势大 // 纵轴满足度（正向情感得分）、横轴人群规模（命中率）
F7 情感得分（可复算）
正向情感得分 = 强烈正向占比 + 中等正向占比 × 0.5
负向情感得分 = 强烈负向占比 + 中等负向占比 × 0.5
标签命中比率 = 命中该标签评论数 ÷ 该维度覆盖的独立评论总数 // 同评论同维度多标签只计 1 次（执行标准）
口径裁定：命中率分母以 step5 原文口径为执行标准；课堂 P37 板书的「该维度所有标签命中数量总和」仅作教学说法。两式结果不同，正式跑数与立项评审一律用 step5 口径，不得混用。

渐进式 vs 突破式 P04

渐进式 Incremental · 一个字「更好」

  • 产品未升级：原基础上的迭代与优化
  • 焦点在产品属性（性能/设计/体验）
  • 目标人群、场景、核心卖点不变
  • 满足已知且已被满足的需求，只是「更好」

突破式 Breakthrough · 一个字「不同」

  • 概念创新：提供全新价值主张
  • 引入新卖点或新场景，创造新购买理由
  • 吸引全新人群或开拓全新场景，可催生新品类
  • 解决用户「不知道自己需要」的问题
🗣

先回答你要的是「更好」还是「不同」。这句话决定后面五个环节的动作、验证方式和营销语言。多数团队的实际错误是：用渐进式的预算和验证流程，去赌一个突破式的结果。

环节渐进式 · 核心动作 / 目标突破式 · 核心动作 / 目标

③ 产品创新属性优化，功能持续升级 / 更好用、更省心概念创新，创造全新品类 / 从未有过的产品形态

从需求到创新 · 两条通路 P10–P12

已知需求 → 渐进式

客诉/退货工单 · VOC 洞察 · 搜索词 · 达人采访 · AI 访谈 · 问卷调研

产品策略 · 三圆 + 公式 P13

高优细分市场 = 重要性高 × 满意度低 × 可实现性大
◉

用户在意

重要性高的任务。证据：step5 命中率 + step6/step8 优先改进象限

◉

竞品没做好

高频差评。证据：step4 打标后按标签聚合

◉

🗣

什么是 VOC · 三个权威口径 P15

ASQ · 六西格玛

系统收集客户诉求，将客户期望转化为可衡量关键质量特性（CTQ）的流程。

①纯情绪/广告/乱码→0 ②明确偏离主题→0 ③满足任一判1→1 ④剩余用判0兜底。判 1 共 7 条、判 0 共 11 条；禁止先判0再判1。

  • 模板化相似：同一前缀（前 20 字符相同）出现 ≥3 次 → 0（最可靠信号）

6 段参考文本 300–500 词，余弦相似度阈值建议 0.10–0.20；用 20 条已知判1作正样本，取第 10 百分位为阈值下限（确保 90% 正样本命中）。

  • 语义等同（核心含义 100% 一致）→ 保留最精准者
  • 语义近义（无独立统计价值）→ 保留覆盖最广者
  • 语义差异（有独立业务价值）→ 完整保留不合并

归属优先级：①核心语义匹配 ②出现频次最高 ③行业通用规范 ④业务覆盖广度。三级结构固定：模块→维度→标签，每标签仅一个最优模块+维度。字段结构 100% 一致。

争议标签：边界模糊无法判断是否近义的，优先保留原始标签、不强制合并，并在报告中说明。
翻车模式：机械补齐对称标签（青年/中年、价格不敏感、低频使用）让体系「看起来完整」，等于主动引入无证据标签。
